# ReAct / Agentic Agency Leads

Date: 2026-04-12

Context:
- Screened against the current `research.csv` inventory in this repo.
- Focused on net-new firms not already present in the CSV.
- Excluded shops whose primary positioning is `n8n`, `Make`, `Zapier`, or generic low-code workflow automation.
- Filtered instead for firms selling custom AI agents, multi-agent systems, agent orchestration, tool-using agents, or enterprise agentic workflows.

Important note:
- Very few agencies use the term `ReAct` directly on public marketing pages.
- In most cases below, `ReAct fit` is an inference from their explicit language around reasoning, planning, tools, orchestration, memory, and multi-step autonomous execution.

## Highest-Fit Leads

### 1. Xenoss
- Domain: https://xenoss.io/
- Why it fits: Explicit multi-agent systems positioning. Their public pages describe planner-executor agent architecture, agent orchestration, memory layers, tool chaining, and enterprise deployment.
- ReAct fit: High, inferred from planner/executor + tool chaining + adaptive loops.
- Evidence:
  - https://xenoss.io/solutions/enterprise-multi-agent-systems
  - https://xenoss.io/solutions/enterprise-ai-agents
- Notes: Strongest fit in this pass if the target is true agentic systems rather than chatbot vendors.

### 2. Virgent AI
- Domain: https://www.virgent.ai/
- Why it fits: Sells custom AI agents, multi-agent systems, workflow orchestration, and exposes a live multi-agent sandbox demo.
- ReAct fit: High, inferred from multi-agent orchestration, task coordination, and production-ready agents that act across systems.
- Evidence:
  - https://www.virgent.ai/agents
  - https://www.virgent.ai/agents/demos/agent-sandbox
  - https://www.virgent.ai/case-studies/multi-agent-orchestration-sandbox
- Notes: Smaller and more clearly AI-native than big consultancies.

### 3. Orases
- Domain: https://orases.com/
- Why it fits: Publicly markets multi-agent systems, autonomous agents, deliberative agents, hierarchical agents, and role-based coordination.
- ReAct fit: High, inferred from multi-agent coordination plus agent types built around autonomy and deliberation.
- Evidence:
  - https://orases.com/ai-agent-development/multi-agent-systems/
  - https://orases.com/services/
- Notes: Older established firm, so less AI-native branding than startups, but the services page is materially aligned.

### 4. HSO
- Domain: https://www.hso.com/
- Why it fits: Explicit `agentic AI consulting` offer with custom agent development, orchestrator-agent architecture, pre-built agents, governance, and enterprise rollout.
- ReAct fit: High, inferred from language around agents that perceive, reason, decide, and act across business systems.
- Evidence:
  - https://www.hso.com/artificial-intelligence/agentic/
  - https://www.hso.com/artificial-intelligence/agent/
  - https://www.hso.com/consultancy-offering/agentic-ai-advisory-service/
- Notes: Enterprise Microsoft-stack specialist. Good fit for larger-buyer market mapping, less useful if the target list should stay boutique.

### 5. Nirman Techlab
- Domain: https://ntechlab.io/
- Why it fits: Markets `Enterprise AI Engineering` around secure agentic workflows, production RAG, and autonomous multi-agent systems integrated into ERP/CRM.
- ReAct fit: High, inferred from agentic workflow orchestration and task decomposition via specialized agents.
- Evidence:
  - https://ntechlab.io/services/enterprise-ai-engineering/
  - https://ntechlab.io/
- Notes: One of the clearest “agentic workflow” messages outside the major consultancies.

## Excluded In This Pass

- Softude: real AI-agent services page, but current public positioning reads more like broad AI services than strong ReAct/multi-agent specialization.
- Search Intelligence: has AI-agents messaging, but the broader agency brand still appears SEO/marketing-led rather than clearly agent-systems-led.

## Recommended Next Moves

1. Add the highest-fit five to the pipeline first: Xenoss, Virgent AI, Orases, HSO, Nirman Techlab.
2. Research them with the existing repo workflow: homepage, services, about, pricing, case studies, Clutch/LinkedIn verification.
