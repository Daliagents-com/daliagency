# Lifehacks that still work (Dali stack)

Each item: mechanism, effort, impact, verify, when wrong.
Not influencer spam.

## P0 - this week

### L1 - GSC + sitemap
- **Mechanism:** Indexing API surface + query data.
- **Effort:** 30-60 min.
- **Impact:** Unlocks all measurement.
- **Verify:** Sitemap "Success"; URLs appear in Pages.
- **Wrong when:** You never open GSC again.

### L2 - Request indexing on 5 money pages
- **Mechanism:** Faster discovery of important URLs.
- **Effort:** 15 min after GSC.
- **Impact:** Medium on new sites.
- **Verify:** URL Inspection → indexed.
- **Wrong when:** Spam-submitting hundreds of thin URLs.

### L3 - Internal links from high-authority templates
- **Mechanism:** PageRank-ish flow + crawl discovery.
- **Effort:** 1-2 h code/copy.
- **Impact:** High for orphan blog.
- **Verify:** Crawl home/solutions/footer → blog hubs.
- **Wrong when:** Keyword-stuffed footer spam.

### L4 - Organization sameAs after profiles exist
- **Mechanism:** Entity consolidation for search + AI.
- **Effort:** 10 min code once URLs ready.
- **Impact:** Medium-high for GEO.
- **Verify:** Rich Results / schema validator + Knowledge-ish consistency.
- **Wrong when:** Linking empty or fake profiles.

### L5 - One brand string everywhere
- **Mechanism:** Branded query + entity matching.
- **Effort:** Policy only.
- **Impact:** Compounding.
- **Verify:** Site, LI, Clutch, proposals say "Dali" / "Dali Agents" consistently.
- **Wrong when:** Random renames every month.

## P1 - this month

### L6 - FAQ with real questions (already on posts)
- **Mechanism:** Extractable Q/A for people and models.
- **Effort:** Already built; keep using.
- **Impact:** Medium.
- **Verify:** FAQ accordion works; questions match real queries later from GSC.
- **Wrong when:** Fake FAQs nobody asks.

### L7 - Bing Webmaster + IndexNow
- **Mechanism:** Secondary index / partners.
- **Effort:** 30 min.
- **Impact:** Low-medium.
- **Verify:** Sitemap accepted.
- **Wrong when:** Treating Bing as primary.

### L8 - Author identity on posts
- **Mechanism:** E-E-A-T.
- **Effort:** Small UI + optional about page.
- **Impact:** Medium for trust.
- **Verify:** Visible author + link to founder profiles.
- **Wrong when:** Fake "AI research team of 40".

### L9 - Compress only critical images / keep heroes
- **Mechanism:** LCP.
- **Effort:** Ongoing.
- **Impact:** Medium technical.
- **Verify:** PageSpeed field/lab later.
- **Wrong when:** Destroying hero quality for 5KB.

### L10 - Rewrite from GSC 11-20 later
- **Mechanism:** Push almost-ranking pages over the fold.
- **Effort:** Weekly once data exists.
- **Impact:** High when inventory is large.
- **Verify:** Position/CTR improve 2-4 weeks after rewrite.
- **Wrong when:** Rewriting with no query data (guessing).

## Deprioritize

- llms.txt as ranking strategy.
- Mass directory spam.
- Buying links.
- AI-only "GEO tools" without primary-source alignment.
