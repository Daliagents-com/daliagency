## 1. Цель по доходу (лесенка)

| Ступень | Цель | Смысл ступени |
|---|---|---|
| Сейчас | $2,000/mo | Минималка, доказать что оффер покупают. Скорость важнее позиционирования |
| Далее | $5,000/mo | 2-3 ретейнера или 1 ретейнер + 1-2 проекта в месяц |
| Потом | $10,000/mo | Обойма пакетов + входящий поток (кейсы с цифрами опубликованы) |

Следствие для «сейчас»: продавать туда, где деньги уже лежат (маркетплейсы, депрекейшн-паника), а не строить бренд-воронку.
Бренд-воронка - инструмент ступени $5k+.

## 2. Позиционирование (ставка)

Одной строкой: **«Мы берём агентов - чужих, сломанных, депрекейтнутых - и делаем так, чтобы они работали в проде. Навсегда».**

Почему: рынок сместился с «строить агентов» (2024-25) на «поддерживать агентов работающими» (2025-26).
Ниша agent ops / maintenance - 9/10: тулинг капитализирован (Braintrust $80M @ $800M, Langfuse -> ClickHouse), сервисный слой пуст, листиклов нет.
Это Fractional-стори («PoC-to-production gap») на слое, где Fractional уже нет.

## 3. Связка офферов: клинья -> аннуитет

```
Входные клинья (проекты, фикс-прайс):     Аннуитет:
- Pilot / agent rescue               \
- Миграции (Assistants API, LangChain) --> Agent Ops Retainer
- Evals-спринт                       /     (monitoring, evals, drift,
- Claude Code enablement            /       cost governance)
```

Все клинья кормят ОДИН ретейнер.
В маркетинге показывается один клин за раз; меню целиком - только в продажах после входа.

### Пакеты - УТВЕРЖДЁННАЯ СЕТКА (2026-08-02, решение Давида: -25% от рыночной для набора клиентов)

Витрина: Build / Rescue / Run. Вход: бесплатный видео-аудит (лидген-период). Гарантия везде: acceptance test не пройден - не платишь.

| Run | Agent Care Pro | $1,490/mo: + cost governance, SLA 24h, квартальный roadmap |

Founding-client механика: первым 5 клиентам -25% в обмен на публичный кейс с метриками.
Листовая цена не снижается; скидка уходит, кейсы остаются.
На сайте формат «from $X» + founding-бейдж.
Ниже этой сетки не опускаться: фриланс-пол = худшие клиенты, нулевой retention (GigRadar: премиум-бид отвечают 16.4% vs 8.8%).

Математика минималки: цель $2,000/mo = 1-2 ops-ретейнера ИЛИ 1 миграция в месяц.
$5k = 2-3 ретейнера + проект.
$10k = 4-5 ретейнеров + 1-2 проекта/мес.

## 4. Срочное окно (до конца ноября 2026)

Миграционная кампания - самый дешёвый набор первых клиентов:

- OpenAI Assistants API умирает **26 августа 2026** (через ~3 недели).
- OpenAI Agent Builder / Evals dashboard - 30 ноября 2026.
- LangChain AgentExecutor EOL - декабрь 2026.
- Выделенных миграционных агентств не существует (проверено рисерчем 2026-08-02).

Механика: найти тех, у кого это в проде (публичные вопросы на форумах OpenAI/Stack Overflow, GitHub-репо с Assistants API, Upwork-заказы) -> персональное видео «вот что у вас сломается 26 августа, вот план» -> фикс-прайс миграция -> апселл ops-ретейнер.

## 5. Правила из рисерча (не нарушать)

- Каждый кейс публикуется с числом в заголовке (формат Fractional: «минус 80% галлюцинаций»).
- Fixed-price, не почасовка (модель LeftClick) - снимает главное SMB-возражение.
- Ретейнер обосновывается языком 2026: LLM drift monitoring, prompt versioning, eval regression, cost governance.
- Вход в маркетинге - ОДНА проблема, не меню.
- Generic «custom AI agents» позиционирование - запрещено (рынок объявил мёртвым).

## 6. Маркетплейс-рисерч (готово 2026-08-02)

### Upwork

- Спрос: AI Integration +178% YoY, «AI Apps & Integration» x2 при падении остальных 11 категорий на -9%.
- Конкуренция: средний reply rate 7.4% (13-14 заявок на ответ); AI/ML - переловленная категория; <9% заказов открыты новичкам.
- Контринтуиция (GigRadar, 134K заявок): бид в 2-5x от бюджета отвечают 16.4% vs 8.8% при попадании в бюджет. Целить клиентов с lifetime spend $1-5K (лучший reply 8.15%), не китов. Заявка в первые 4-5 минут после поста (настроить Vollna RSS -> n8n алерт).
- Бюджеты: Zapier->n8n миграция $800-3,500; AI agent/LLM интеграция $1,000-5,000+; AI-тег платит 2-3x против обычной автоматизации. Voice (Vapi/GHL) - многомесячные сабконтракты от GHL-агентств; категория «почините voice-агента» уже существует. MCP - отдельная категория найма Upwork, конкуренция тонкая.
- Fiverr - гонка на дно ($5-80), скип. Toptal - веттинг неделями, не влезает в окно 30-60 дней.

### Сборка $2,000/mo (30-60 дней)

Месяц 1: 2 фикс-билда по $1,000-2,500 (30-60 таргетных заявок, 80-120 connects ~$24-36).
Каждый билд конвертить в $500/mo maintenance-ретейнер (шаблон в ad-copy-pack, B5).
Месяц 2: 2 ретейнера ($1,000 MRR) + 1 билд = цель закрыта, дальше компаундится.

### Миграции с Assistants API - подтверждено белое пятно

- Дедлайн жёсткий: 26 августа, без продления. Azure копирует (Assistants тоже ретайрится) - аудитория x2.
- В треде форума OpenAI агентства паникуют («many of my clients are using assistants»), платных миграционных офферов НЕТ, заказов на Upwork НЕТ - спрос собирают только SEO-статьи вендоров.
- Вывод: это аутбаунд-ниша (искать по GitHub-репо и форумам, слать видео), не маркетплейс. Вторая волна после 26-го: «мой бот умер» rescue.

### fl.ru / kwork - скип как канал

- Та же работа в 5-10x дешевле: боты 5-7K RUB при 7-44 откликах; 80% задач <10K RUB.
- Русскоязычные деньги уровня Upwork (AI-агенты 50-300K RUB, поддержка 10-20K RUB/mo) - в прямом B2B и Telegram, не на биржах.
- RU-канал использовать как: (а) прямой B2B-аутрич на русском, (б) part-time «трудоустройство» 80-150K RUB/mo как базовый ретейнер-аналог.

- Белые пятна: RU-диаспора SMB на Meta (KZ/GE/AM/DE/UAE - ни одного объявления), немецкий язык, «позвони AI сейчас» демо-креативы (ни одного в выборке).

## 9. «Личный агент для бизнеса» как пакет (готово 2026-08-02)

Вердикт: 6/10 как «один общий агент», 8/10 как модульная линейка узких агентов под одним брендом.

- Против общего агента: MIT - 95% пилотов без P&L-эффекта, победители = узкий фокус; Gartner - >40% агентных проектов отменят к 2027; Lindy дрейфует на цепочках 8+ шагов; Sintra тонет в жалобах (breadth over depth не удерживает).
- Что покупают: узкий именованный агент с видимым результатом. Smith.ai $300-2,100/mo [V], GHL-реселлеры $200-600/mo. Узкий агент с реальными интеграциями удерживается в 4-20x дороже общего.
- Платформенный сквиз: Claude Cowork от $20/mo (файлы, scheduled tasks, Small Business bundle), ChatGPT Work. Generic-обёртка мертва; ответ на «почему вы в 50x дороже Claude Pro» = интеграции + accountability + maintenance, проговаривать в сейлз-материалах заранее.
- Пустая ценовая ниша: между $97/mo SaaS-игрушками и $3,000/mo живым ассистентом (Athena).

Рабочая упаковка «AI-операционист»:

- Продаётся как один бренд, доставляется как 2-4 узких агента на общем контексте: lead follow-up + CRM-гигиена, инбокс-триаж, запись/напоминания, еженедельный отчёт владельцу.
- Цены: setup $1,500-5,000 + $500-1,500/mo; премиум $2-2.5K/mo с привязкой к метрике.
- Инфраструктура: Anthropic Managed Agents (scheduled deployments, credential vaults, MCP, память) - API без конечного продукта сверху; кто-то должен быть интегратором, это мы. Маржа: токены единицы долларов против $1K/mo ретейнера.
- Обязательные предохранители (риск #1 - доверие умирает от первого галлюцинированного письма): approval gates на всё исходящее, недельный отчёт «что агент сделал», расширение по одному воркфлоу.
- Стыковка со стратегией: это ещё один клин, заканчивающийся тем же Agent Ops Retainer.

## 10. Инвесторские сигналы: YC/VC 2026-2027 (готово 2026-08-02)

Тезис «agent ops / rescue / keep-it-working» валидирован с пяти сторон:

1. Gartner: >40% агентных проектов отменят к концу 2027 (рост запаса сломанных агентов для rescue).
2. McKinsey-adjacent: 60% затрат агентного AI = «response refinement» - maintenance и есть большая часть TCO.
3. Bessemer [V]: «AI evals станут приватными и заземлёнными - enterprise-деплой вырастет 10x благодаря этому».
4. YC RFS «Self-Maintaining APIs» [V] - YC буквально просит решать нишу депрекейшн-миграций («агент должен сканировать кодбазы клиентов и открывать PR с фиксом»).
5. Forward-deployed engineers wave: Amazon $1B в роль; Menlo [V]: 76% покупают а не строят - купленных агентов кто-то должен оперировать.

Топ-фиты из ранжирования: eval-ops как сервис (10), agent rescue на волне отмен (10), embedded/forward-deployed ретейнеры (9), keep-integrations-alive (8), SMB-трансформация productized (8 - YC сам профинансировал агентство Async в S26).
Анти-рекомендации: не строить продукты в support/sales-агентах, voice-агентах, control-plane'ах - залито капиталом (~8-12 YC-стартапов на батч).

Риски: (а) платформы поглощают reliability-тулинг (Salesforce купил Spindle, Databricks - Quotient); горизонт 18-36 мес до съедения рутинного тира ops; долговечный слой - суждение (evals-дизайн, rescue, миграции), не «смотрим в дашборд»; (б) ни один VC пока не назвал agent-ops отдельным тезисом - белое пятно или сигнал.

## 11. Практики: HN/Reddit ground truth (готово 2026-08-02)

Боль #1 в проде (во всех комьюнити): **тихие провалы / галлюцинированный успех**.
«Агент говорит, что сделано - а не сделано»; агентства сами перестают аудитить выдачу после 4-й недели; в одном коммерческом проекте 28% коммитов - исправление работы агента.
Это прямое торговое обоснование verification/ops-ретейнера.

Что работает (self-reported, [A]):

- Setup + retainer - доминирующая модель: билд $3-7K + $500-1,500/mo; «60% моей выручки - ретейнеры».
- Паттерн первых $2k за 30 дней: 5 локальных клиентов x $399/mo (voice/booking, Vapi/GHL, косты ~$90/mo, маржа 80%+).
- Agent ops для Series A стартапов: $3-6K/mo, явно назван как money vertical.
- Партнёрский канал: $20K MRR за 8 мес через 8 rev-share партнёров, 89% retention, ноль холода.
- Дистрибуция бьёт билдинг: победители - тёплые сети/рефералы (8/10 клиентов по рекомендациям); строгальщики - cold DM в переполненные инбоксы (1-2% ответов, «ни один не закрылся»).

Мёртвое по мнению практиков: cold email/LinkedIn-автоматизация, faceless-контент, memory-слои («новый todo app»), фреймворки, generic AAA с холодным аутричем.

Проверка гипотез:

- Ops/maintenance-ретейнеры: ВАЛИДИРОВАНО (сильнейший сигнал датасета).
- Rescue: ВАЛИДИРОВАНО как категория, конкуренты уже есть (Productionapps.ai, 404media-кавередж); маркетинг тяжёлый, риск lemon market.
- Assistants-миграция: слабо-умеренно - объём обсуждений НИЗКИЙ; короткое окно, только аутбаунд, не inbound-категория.
- Evals: ВАЛИДИРОВАНО как консалтинг, ИНВАЛИДИРОВАНО как продукт («Why eval startups fail»: «звучит как консалтинг») - продавать внутри ретейнера, не standalone.
- «AI employee для SMB»: НЕ валидировано как фрейминг (1-6 апвоутов, скепсис «это софт с ключами от компании») - продавать конкретный outcome (отвеченные звонки, скорость ответа лиду), никогда «AI-сотрудника».
