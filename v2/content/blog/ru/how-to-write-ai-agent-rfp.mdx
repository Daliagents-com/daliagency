## Прямой ответ

Пишите AI agent RFP вокруг одного workflow и pilot acceptance test. Размытые «transform us with AI» RFP дают размытые, дорогие proposals.

## Обязательные секции

Business problem. Current process. Systems. Data classes. Security constraints. Success metrics. Pilot boundary. Timeline. Commercial model. Evaluation scorecard.

## Идеи scorecard

Process understanding. Gate design. Security. Handoff. Price clarity. Relevant experience - без требования fake case stats.

## Что приложить

Sample tickets, redacted threads, field lists, org chart для approvers.

## Типичные провалы RFP

Пятьдесят unrelated use cases. Нет owner. Mandatory proprietary platform без justification.
