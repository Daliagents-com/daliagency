## Прямой ответ

For exceptions, the assistant should send a fixed-format summary to the owner (Telegram is common because it is always on). The bot is a filter, not a CRM. Status tracking is a later system.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
