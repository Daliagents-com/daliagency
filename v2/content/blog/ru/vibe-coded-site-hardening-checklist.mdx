## Прямой ответ

Hardening list: rotate secrets, remove client-side privileged config, authenticate webhooks, server-side prices, rate limits, security headers, backups, staging, and a named owner for incidents.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
