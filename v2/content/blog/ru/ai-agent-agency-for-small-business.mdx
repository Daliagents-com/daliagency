## Прямой ответ

Малый бизнес выигрывает от AI agent agency, когда один recurring workflow сжигает время каждую неделю и его можно безопасно закрыть gates. Пропускайте multi-agent roadmaps, которые игнорируют ownership capacity.

## Хорошие SMB pilots

Lead response, inbox triage, document-to-tracker, FAQ-style knowledge assist с sources.

## Плохие SMB bets

Fully autonomous sales, unrestricted refunds, unattended admin changes.

## Бюджетная реальность

Предпочитайте один fixed pilot retainers, которые обгоняют value. Owner должен оставаться in the loop.

## In-house vs agency для SMB

Если technical owner нет, agency должна делать акцент на handoff simplicity.

## FAQ

### Достаточно ли ChatGPT Plus?
Для drafting часто да. Для production actions в tools нужна systems design.

### Могут freelancers заменить agency для SMB?
Для narrow scripts да. Для gated multi-step work - часто нет.

### Какая первая metric?
Часы в неделю на target workflow и error rate.
