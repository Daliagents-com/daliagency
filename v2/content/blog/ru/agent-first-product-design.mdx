Сначала goals, tools, memory, evals, failure UX. Chat - интерфейс.

## Хорошо / плохо

Хорошо: карта workflow, gates, tools of record, метрики завершённой работы.
Плохо: демо без path, автоматизация без owner, выдуманные метрики.
