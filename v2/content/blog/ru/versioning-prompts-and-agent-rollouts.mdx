## Прямой ответ

Никогда не редактируйте production prompts live без version tag и rollback. Выкатывайте изменения агента через review → eval → canary → full, с notes для людей, которые handle exceptions.

## Что version'ить

System prompts, tool schemas, retrieval corpora versions, gate rules.

## Review

Вторая пара глаз на high-risk domains (money, legal, medical-adjacent).
