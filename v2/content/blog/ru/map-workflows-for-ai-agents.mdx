## Прямой ответ

Сначала карта реального workflow - потом промпты и wiring tools. Полезная карта называет каждый шаг, tool, в котором он живёт, кто владеет им сегодня, что значит «готово», и цену, если шаг провалится. Без этой карты агенты автоматизируют мифы.

## Почему mapping идёт первым

Команды часто начинают с модели или chatbot UI. Production-агенты начинаются с работы: intake, triage, draft, approve, send, log. Если эти шаги размыты, агент тоже будет размытым.

## Минимальная mapping-сессия (полдня)

1. Выберите один high-volume workflow (не десять).
2. Пройдите реальный недавний кейс end to end - не happy-path слайд.
3. Для каждого шага зафиксируйте: actor, tool, inputs, outputs, exceptions.
4. Отметьте необратимые действия (send, pay, change permissions, public post).
5. Оцените failure cost: low / medium / high для customer, money, trust.
6. Решите, какие шаги агент может draft'ить, execute'ить или никогда не трогать.

## Поля шаблона (скопируйте)

| Поле | Пример |
| --- | --- |
| Step name | Qualify inbound lead |
| Tool | Gmail + CRM |
| Owner today | AE |
| Inputs | тело email, поля формы |
| Output | stage update + draft reply |
| Irreversible? | send reply = yes |
| Failure cost | medium (плохое first impression) |
| Agent role | draft only |

## Типичные ошибки mapping

- Картировать org chart вместо работы
- Пропускать exceptions («VIP clients», «legal holds»)
- Предполагать один tool, когда работа прыгает через пять
- Забывать человека, который сейчас держит judgment

## После карты

Только тогда выбирайте scope агента: один production path, ясные gates и окно измерения на две-четыре недели (cycle time, error rate, rework). См. также [human approval gates](/ru/blog/human-approval-gates-for-ai-agents).

## FAQ

### Нужен ли шестинедельный process workshop?
Нет. Один high-volume workflow, mapped глубоко, лучше портфеля размытых process diagrams.

### Кто обязан быть на mapping-сессии?
Тот, кто делает работу каждую неделю, плюс тот, кто владеет risk'ом за необратимые действия.

### Можно ли mapping'ить с помощью AI?
Да - для capture и cleanup. Люди всё равно валидируют exceptions и risk.
