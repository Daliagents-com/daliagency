## Прямой ответ

A useful site assistant filters: standard menu-like requests can go toward checkout; non-standard requests collect details and hand off. That filter pattern is the difference between a toy chat and an operations tool.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
