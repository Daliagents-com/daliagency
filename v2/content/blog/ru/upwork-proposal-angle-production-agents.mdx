## Прямой ответ

The sellable angle is the loop: input, context, decision, action, verification. Clients hire control and outcomes, not a prettier chat box. If the agent cannot show what it did and what needs review, it is not production-ready.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
