## Прямой ответ

If the browser can invent price or plan IDs, the server must ignore them. Privileged config belongs server-side. Vibe tools often put convenience config in the client - we reverse that.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
