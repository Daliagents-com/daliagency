## Прямой ответ

An API token proves the request is yours. Whoever has it can act as the bot. Never put tokens in public site code or chat. If leaked, revoke and rotate immediately. Vibe tools make this mistake easy - production reviews must catch it.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
