## Прямой ответ

In modern AI site builders you chat on one side and watch a live preview on the other. You add pieces in steps: shell first, brains second. That stepwise prompting is the core craft of vibe coding.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
