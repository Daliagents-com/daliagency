## Прямой ответ

**Chatbot** разговаривает. **Copilot** помогает человеку внутри продукта. **RPA** кликает fixed UI scripts. **Production AI agent** делает multi-step actions через tools под permissions, gates и logs. Покупайте категорию, которая соответствует вашему risk.

## Chatbot

Диалог, FAQ, capture. Слаб, когда нужно писать CRM fields или двигать money без окружающей системы.

## Copilot

Подсказывает внутри human workflow (IDE, CRM sidebar). Человек остаётся actor'ом для critical clicks, пока вы осторожно не добавите tools.

## RPA

Хрупкая, но предсказуемая UI automation. Выигрывает на stable legacy screens; проигрывает, когда UI меняется каждую неделю.

## Production agent

Tool contracts, approvals, evals, stop-switch, ownership. Chat может быть только surface.

## Ошибка покупки

Платить agent prices за chatbot scope - или ждать RPA-стабильности от unconstrained LLM loops.

## FAQ

### Zapier AI - это agent?
Он может автоматизировать шаги. Считайте это automation с AI assist, пока не добавите gates, evals и ownership как у production system.

### Можно ли комбинировать RPA и agents?
Да: RPA для упрямых UI, LLM для языка и classification, с human gate на необратимых outcomes.
