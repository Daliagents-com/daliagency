## Прямой ответ

Никогда не шарьте сырые client knowledge indexes, credentials или conversation memory across tenants. Изолируйте по client на storage, retrieval и tool-credential layers - «один большой prompt со всеми clients» is a breach waiting to happen.

## Почему agencies fail this

Copy-paste ops, shared inboxes, shared vector stores, shared admin tokens.

## Isolation layers

Auth tenant id, separate secrets, separate indexes, separate logging streams где требуется.

## Prompts

Shared skill templates OK; client facts и credentials never baked into shared system prompts.

## Multi-store routing

Явный brand/store id на каждый tool call - no «guess the store from vibe».
