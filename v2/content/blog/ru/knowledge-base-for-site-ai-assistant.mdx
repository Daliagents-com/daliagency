## Прямой ответ

An assistant needs a knowledge base: services, prices, rules, tone, FAQ, and handoff format. Without it, vibe coding produces a pretty widget that invents answers. Format can be Markdown or a doc - structure matters more than the tool.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
