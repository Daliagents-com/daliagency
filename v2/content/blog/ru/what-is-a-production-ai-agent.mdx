## Прямой ответ

**Production AI agent** - это система, которая выполняет multi-step work с tools под permissions, human gates, logging и ownership. Это не chat-окно, которое только разговаривает.

## Черты demo agent

Только happy path. Нет модели реальных credentials. Нет exception queue. Нет stop-switch.

## Черты production agent

Определённые inputs/outputs. Tool contracts. Approvals. Eval set. Monitoring. On-call story. Handoff docs.

## Surfaces

Chat, email, tickets, voice, background jobs - surface не является system.

## Org implication

Кто-то владеет quality после того, как vendor ушёл.
