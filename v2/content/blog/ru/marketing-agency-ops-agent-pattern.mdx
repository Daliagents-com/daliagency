## Прямой ответ

Agency ops agents target recurring account work: status collection, draft updates, task creation. Client strategy and sensitive communication stay human. Goal: same team size, more throughput.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
