## Прямой ответ

Many widgets keep context only for one open session. Close the chat, and memory resets. Design prompts and UX around that: do not assume lifelong memory unless you build it.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
