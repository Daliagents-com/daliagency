## Прямой ответ

Оформляйте каждый AI agent pilot как один workflow, один primary tool path, explicit gates, pass/fail acceptance test и named owners. Всё остальное - phase two.

## Поля template

Имя workflow. Trigger. Tools. Inputs. Allowed actions. Forbidden actions. Human gate points. Success metrics. Data access. Timeline. Exclusions.

## Пример формы acceptance test

На 20 real historical cases: zero silent duplicates, required fields complete выше threshold, каждый low-confidence case создаёт exception.

## Как использовать с vendors

Отправьте заполненный template до pricing. Отклоняйте quotes, которые игнорируют exclusions.

## Типичные ошибки

Три workflows в одном pilot. Нет owner для approvals. Success = «feels smarter» без measure.

## FAQ

### Какой длины должен быть pilot?
Достаточно, чтобы прогнать real cases и поправить gates - часто weeks, не weekend.

### Могут marketing и ops делить один pilot?
Предпочитайте separate pilots с separate acceptance tests.

### Кто заполняет template?
Business owner workflow плюс тот, кто контролирует tools.
