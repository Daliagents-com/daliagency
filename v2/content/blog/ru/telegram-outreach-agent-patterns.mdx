## Прямой ответ

Outreach agents can handle high daily volume, but compliance, consent, and brand risk dominate. We design rate limits, templates, stop lists, and human review for sensitive threads.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
