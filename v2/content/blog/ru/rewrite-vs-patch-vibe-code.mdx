## Прямой ответ

Patch when structure is sound and issues are localized. Rewrite the critical path when auth, payments, or multi-tenant data are entangled with generated spaghetti. Keep marketing pages if they are stable.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
