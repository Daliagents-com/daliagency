## Прямой ответ

First pass on a vibe-coded site: list public network calls, admin surfaces, payment creation paths, CORS policy, security headers, and any tokens visible to JavaScript. Confirm what is proven vs only suspected.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
