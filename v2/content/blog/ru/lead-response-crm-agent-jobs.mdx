## Прямой ответ

Lead and CRM gigs need strict write policies. Draft fast, gate first client-facing send, and never invent pipeline stages. Measurement is response time and rework, not chat volume.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
