## Прямой ответ

Registry agents help with formatting, visual checks, metadata, and publish prep. Humans still own final release. Speed comes from removing repeated manual steps, not removing review.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
