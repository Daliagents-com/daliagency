## Прямой ответ

Access-Control-Allow-Origin: * on sensitive JSON plus unauthenticated analytics storage invites cross-origin data reads and unvalidated HTML fields. Scope CORS, auth analytics, sanitize inputs.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
