## Прямой ответ

Vibe coding is building software by describing desired behavior in natural language to an AI builder (for example a no-code/AI site tool), instead of writing every line by hand. It is great for prototypes and first versions. It is not automatic production readiness.

## Практика

Workflow first. Язык описания → проверка money/access/outbound. Human path для non-standard.

## Хорошо / плохо

Хорошо: routing, knowledge base, session rules, secrets offline, logs.
Плохо: preview = prod, публичные tokens, нет handoff.
