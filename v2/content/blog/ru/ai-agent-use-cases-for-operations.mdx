## Прямой ответ

Operations teams должны стартовать AI-агентов на intake, routing, document-to-system updates и status sync - всегда с exception queues и human gates на irreversible writes.

## High-fit use cases

Парсить inbound requests в trackers. Валидировать required fields. Черновить status updates. Флагировать anomalies.

## Low-fit early use cases

Платежи vendors без supervision. Legal commitments без review. Тихое удаление records.

## Design pattern

Standard path automated. Non-standard path - к людям. Полный log trail.

## Pilot suggestion

Один document type или один intake channel сначала.
