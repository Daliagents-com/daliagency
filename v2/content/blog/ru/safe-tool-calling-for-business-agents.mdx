## Прямой ответ

Дайте агентам **маленькие tool allowlists**, least-privilege credentials, явные schemas, loop limits и human gates на необратимых tools. Tool calling без scopes - путь, которым demos становятся incidents.

## Tool calling vs prompting

Prompting производит текст. Tool calling позволяет модели выбирать structured actions (CRM update, search, send). Action layer - место, где живёт business risk.

## Allowlists и schemas

Каждый tool нуждается в имени, JSON schema, max frequency и owner. Отклоняйте free-form «run any code» в production ops.

## Permissions

Отделяйте read tools от write tools. Отдельные staging credentials. Нет god-mode service accounts в agent runtime.

## Loop и spend limits

Max steps, max tokens, max tool calls, wall-clock timeout. Infinite replanning - это bug, не intelligence.

## Assistants platforms

Hosted assistant APIs помогают bootstrap. Вы всё равно владеете scopes, logging и gates для business actions.

## FAQ

### Должен ли агент execute SQL на production?
Почти никогда напрямую. Предпочитайте constrained APIs и audited mutations.

### Как подтверждать high-risk tools?
Human approval gate с evidence pack: inputs, intended action, confidence, source.
