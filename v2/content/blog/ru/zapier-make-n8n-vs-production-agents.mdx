## Прямой ответ

Используйте **Zapier/Make/n8n** для надёжного glue между apps с clear triggers. Добавляйте **production agents**, когда language understanding, messy inputs и gated multi-step decisions - это job, и вам нужны evals и ownership.

## Когда no-code выигрывает

Stable triggers, deterministic field maps, low NLP need, internal ops с low blast radius.

## Когда no-code ломается

Ambiguous emails, policy-heavy replies, branching that needs judgment, strict audit requirements.

## n8n + LLM

Мощный prototype path. Всё равно нужны gates, secrets hygiene и acceptance tests, чтобы быть «production».

## Custom/agent systems

Tool contracts, HITL, observability, tenant isolation, staged rollout.

## SQL from automations

Предпочитайте constrained APIs вместо open production SQL из любого automation layer.
