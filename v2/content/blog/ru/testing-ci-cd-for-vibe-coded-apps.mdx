## Прямой ответ

AI-generated UI - не free pass on quality. Добавьте **smoke tests**, critical-path e2e for money/auth, CI on every PR и written handoff map before real users scale.

## Minimum tests

Auth login, checkout or lead form, webhook receiver, permission denial cases.

## CI

Lint, typecheck, unit/smoke, block merge on red.

## Staging

Environment parity for secrets и payments test mode.

## Handoff to engineers

Architecture sketch, known footguns, seed data, how to run locally.

## What AI tests miss

Race conditions, entitlement bugs, multi-tenant leaks.
