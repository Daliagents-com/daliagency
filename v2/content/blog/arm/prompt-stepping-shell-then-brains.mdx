## Ուղիղ պատասխան

Ask for the shell first (button, layout, empty widget), then attach intelligence. One giant prompt creates opaque failures. Stepped prompts create checkpoints you can test.

## Պրակտիկա

Workflow first։ Secrets-ը client JS-ում չեն։ Human path exceptions-ի համար։
