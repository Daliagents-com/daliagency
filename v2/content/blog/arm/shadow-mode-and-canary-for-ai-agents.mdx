## Ուղիղ պատասխան

Ship արեք agents ինչպես risky software. **shadow mode** (predict առանց acting), հետո **canary** (փոքր % կամ մեկ segment), versioned prompts-ով և instant rollback-ով։ Big-bang «բոլոր tickets-ը վաղը»-ն այն է, թե ինչպես trust-ը մեռնում է։

## Shadow mode

Agent-ը propose է անում actions. humans-ը կամ current process-ը դեռ act են անում։ Համեմատեք offline։

## Canary

Մեկ queue, մեկ locale, մեկ VIP-excluded segment։ Հետևեք exception և override rates-ին։

## Prompt/version control

Դիտեք prompts-ը և tool schemas-ը ինչպես code. review, tag, release notes։

## Feature flags

Flip արեք behavior առանց ամբողջ stack-ը redeploy անելու, երբ հնարավոր է։

## Rollback

Known-good prompt + tool config մեկ click-ով։ Practice արեք։

## FAQ

### Որքա՞ն երկար shadow։
Մինչև metrics-ը beat անեն baseline-ը golden set-ի և live sample-ի վրա - ոչ fixed marketing number։

### Canary-ն միայն enterprises-ի՞ համար է։
SMB-ները կարող են canary անել by customer segment կամ channel։
