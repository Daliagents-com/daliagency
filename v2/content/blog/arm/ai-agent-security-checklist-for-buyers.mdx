## Ուղիղ պատասխան

Նախքան agent-ները production-ում գործեն, lock արեք secrets, least privilege, outbound gates, audit logs և stop-switch։ Security-ն pilot design-ի մաս է, ոչ polish phase։

## Secrets և keys

Ոչ tokens client JS-ում կամ public repos-ում։ Rotate արեք ամեն ինչ, որ երբևէ commit է արվել։

## Permissions

Least privilege per tool։ Առանձնացրեք prod և test։ Ոչ shared god-mode service accounts առանց review-ի։

## Actions

Gate արեք payments, emails, deletes, permission changes, public posts։

## Observability

Log արեք inputs, tool calls, outputs, approvals։ Պահեք բավական՝ incidents debug անելու համար։

## Vendor access

Time-boxed, minimal, revocable։ Գրավոր data handling rules։
