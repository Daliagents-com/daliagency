## Ուղիղ պատասխան

Երբեք մի share արեք raw client knowledge indexes, credentials կամ conversation memory across tenants։ Isolate արեք by client storage, retrieval և tool-credential layers-ում - «մեկ մեծ prompt բոլոր clients-ով»-ը breach է, որ սպասում է տեղի ունենալու։

## Ինչու agencies-ը fail են լինում սա

Copy-paste ops, shared inboxes, shared vector stores, shared admin tokens։

## Isolation layers

Auth tenant id, separate secrets, separate indexes, separate logging streams, որտեղ required է։

## Prompts

Shared skill templates OK. client facts և credentials երբեք baked չեն shared system prompts-ում։

## Multi-store routing

Explicit brand/store id ամեն tool call-ի վրա - ոչ «guess the store from vibe»։
