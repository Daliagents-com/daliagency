## Ուղիղ պատասխան

Demo logins-ը և wide-open tables-ը auth չեն։ Ship արեք real session handling, least-privilege database rules (RLS) և migrations review-ով - կամ plan արեք rewrite of the data plane։

## Auth failures vibe apps-ում

Client-only checks, shared passwords, tokens localStorage-ում, missing email verification։

## Sessions

HTTP-only cookies կամ proven session libraries. rotate արեք secrets։

## Databases

Enable արեք RLS/policies. no anon write production tables-ին. separate service roles։

## Migrations

Expand/contract, backups, staging first։ AI-generated SQL-ը untrusted է, մինչև review։

## Երբ rewrite անել data plane

Եթե permissions-ը չեն կարող coherent դառնալ առանց scaffold-ի հետ կռվելու։
