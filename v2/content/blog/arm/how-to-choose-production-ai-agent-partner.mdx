## Ուղիղ պատասխան

Ընտրեք partner, որը կարող է ship անել մեկ production path gates-ով, logs-ով և handoff-ով - ոչ partner, որը միայն multi-agent theater է ներկայացնում։

## Production նշանակում է irreversible գործողությունները վերահսկված են

Email, CRM writes, payments, admin և public posts պետք ունենան explicit rules։

## Partner checklist

Workflow mapping skill։ Tool integration honesty։ Evaluation plan։ Security basics։ Documentation quality։

## Pilot design որպես filter

Եթե չեն կարող առաջարկել fixed pilot acceptance test-ով, պատրաստ չեն production աշխատանքի։

## Culture fit

Պետք է challenge անեն վատ automation գաղափարները, ոչ unlimited autonomy վաճառեն։

## Ինչպես է Dali-ն տեղավորվում

Dali-ի pilot-ները կառուցված են որպես production path-եր։ Review արեք [vibe-code rescue](/arm/solutions/vibe-code-rescue) և այլ [solutions](/arm/solutions)։

## FAQ

### Պե՞տք են ML PhD-ներ vendor team-ում։
Սովորաբար ոչ։ Պետք են systems thinking, integrations և ops։

### Multi-agent architecture պարտադի՞ր է։
Ոչ։ Շատ wins մեկ well-gated agent path են։

### Ինչպե՞ս արագ թեստավորել partner-ին։
Paid audit մեկ workflow-ի վրա՝ գրավոր findings-ով։
