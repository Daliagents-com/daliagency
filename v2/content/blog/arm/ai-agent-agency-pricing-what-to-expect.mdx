## Ուղիղ պատասխան

Սպասեք նախ վճարովի discovery կամ audit, հետո fixed-price pilot մեկ workflow-ի համար, հետո ընտրովի monthly retainer, երբ agent-ն արդեն live է։ Տիպիկ շուկայական միջակայքերը 2026-ին. audit-ներ մոտավորապես $2,000-15,000, մեկ workflow-ի pilot-ներ $10,000-50,000, ops retainer-ներ $1,500-10,000 ամսական։ Էժան unlimited «agents everywhere» package-ները սովորաբար նշանակում են բարակ demo-ներ առանց gates-ի, logging-ի և ownership-ի։

## Եռափուլ կոմերցիոն ձևը

Վստահելի agent գործակալությունների մեծ մասը գինը կառուցում է երեք փուլով։

1. **Discovery կամ audit։** Վճարովի, կարճ, ֆիքսված գնով։ Արդյունքը՝ workflow-ի քարտեզ, ռիսկերի ցուցակ և pilot-ի առաջարկ գրավոր acceptance test-ով։
2. **Fixed-scope pilot։** Մեկ workflow, մեկ acceptance test, անվանված tools, human gates ռիսկային գործողությունների վրա։ Ֆիքսված գին, ֆիքսված ժամկետ։
3. **Ops retainer։** Ընտրովի։ Monitoring, evals, իտերացիա և աջակցություն agent-ի գործարկումից հետո։

Մնացած ամեն ինչը, ինչ կհանդիպեք - hourly consulting, platform license-ներ, outcome fee-ներ - այս երեքի վարիացիաներն են։

## Pricing մոդելների համեմատություն

| Մոդել | Ինչ է օպտիմալացնում | Որտեղ է կոտրվում |
| --- | --- | --- |
| Hourly consulting | Ճկունություն, երբ scope-ը պարզ չէ | Հաշվիչը պտտվում է, մինչ scope-ը drift է անում |
| Fixed-price pilot | Հստակ scope, կիսված ռիսկ | Ավելցուկային պաշար, երբ brief-ը մշուշոտ է |
| Monthly retainer | Մշտական ops և իտերացիա | Standby billing առանց սահմանված SLA-ի |
| Per-agent կամ per-seat license | Վենդորի կանխատեսելի եկամուտ | Վճարում եք պլատֆորմի համար, որը ձեզ գուցե պետք չէ |
| Outcome կամ revenue share | Թղթի վրա հավասարեցված խթաններ | Attribution վեճեր, բարդ պայմանագրեր |

Build-ի համար նախընտրեք fixed pilot, operations-ի համար՝ retainer սահմանված scope-ով։ Նախընտրեք implementation այն tools-ում, որոնց համար արդեն վճարում եք, նոր platform license-ների փոխարեն, եթե նոր tool-ը ինքը product-ը չէ։

## Տիպիկ շուկայական միջակայքեր

Սրանք տիպիկ շուկայական միջակայքեր են, ոչ Dali-ի quote-եր։ Դրանք խիստ տարբերվում են ըստ տարածաշրջանի, վենդորի seniority-ի և այն բանի, թե որքան integration աշխատանք է թաքցնում scope-ը։ Ընկալեք որպես կողմնորոշում, ոչ որպես առաջարկ։

| Հոդված | Տիպիկ շուկայական միջակայք |
| --- | --- |
| Վճարովի discovery կամ audit | $2,000-15,000, սովորաբար 1-3 շաբաթ |
| Fixed-scope pilot, մեկ workflow | $10,000-50,000, սովորաբար 3-8 շաբաթ |
| Ops retainer գործարկումից հետո | $1,500-10,000 ամսական |
| Hourly consulting | $100-300 ժամում |
| LLM usage, մեկ միջին ծավալի workflow | Տասնյակներից մինչև մի քանի հարյուր դոլար ամսական, աճում է ծավալի հետ |

Quote-ը, որն այս միջակայքերից շատ ցածր է, ավտոմատ խաբեություն չէ։ Սովորաբար դա նշանակում է, որ ինչ-որ բան պակասում է. discovery, gates, logging, փաստաթղթեր կամ որևէ մեկը on-call գործարկումից հետո։

Կողմնորոշման համար. Dali-ի սեփական պիլոտները fixed-scope ձևաչափով են՝ $1,900-$3,500՝ ուղղությունից կախված, ընդլայնված տիերը՝ $4,000: Scope-ը ֆիքսվում է կարճ աուդիտից հետո, ուստի գինը պարտավորություն է, ոչ թե գնահատական: Փաթեթային պիլոտներն ավելի էժան են վերևի տիպիկ custom միջակայքերից, որովհետև scope-ը ստանդարտացված է, ոչ թե քայլերն են բաց թողնված:

## Ծախսերի կատեգորիաներ, որոնք գնորդները մոռանում են

Build-ը ամբողջ հաշիվը չէ։ Սրանք բյուջե դրեք առաջին օրվանից։

- **LLM call costs։** Agent-ի ամեն գործարկում token-ներ է ծախսում։ Հարցրեք, թե ով է վճարում API-ի հաշիվը, ինչպես է սահմանափակվում usage-ը և ինչ է լինում, երբ retry ցիկլը սխալ է վարվում։ Ստացեք ամսական գնահատական մեկ workflow-ի համար ձեր իրական ծավալով։
- **Evals-ի պահպանում։** Մոդելները փոխվում են, prompt-ները drift են անում։ Eval set-երը պահպանում են պահանջում, այլապես որակը լուռ դեգրադացվում է։
- **Monitoring և logging։** Ինչ-որ մեկը պետք է կարդա trace-երը, երբ agent-ը տարօրինակ բան է անում։
- **Incident response։** Ով է on-call, ինչ արձագանքման ժամանակով և ինչ գնով։
- **Change management։** Թիմի ուսուցում, runbook-ների թարմացում, gates-ի լայնացում կամ նեղացում վստահության աճի հետ։
- **Աջակցության պատուհան գործարկումից հետո։** Pilot-ն առանց աջակցության շրջանի demo է՝ invoice-ով։

## Ինչ պետք է լինի pilot quote-ում

Production-grade pilot quote-ը կետ առ կետ ներառում է.

- Workflow-ի քարտեզը՝ scope-ի ճշգրիտ քայլերով
- Անվանված integrations և ով է տալիս access-ները
- Գրավոր acceptance test. մուտքեր, սպասվող ելքեր, անցման շեմ
- Gate կանոններ. որ գործողություններն են պահանջում human approval և ով է հաստատում
- Logging և որտեղ են ապրում trace-երը
- Handoff package. փաստաթղթեր, runbook, credentials պլան
- LLM ծախսերի գնահատական և ով է վճարում
- Աջակցության պատուհան go-live-ից հետո
- Հստակ exclusions

Եթե երեք կամ ավելի կետ պակասում է, ձեր առջև pilot-ի հագուստով demo quote է։

| Human approvals-ի մասին ոչ մի խոսք | Autonomy default-ով, ինցիդենտները՝ հետո |
| Անվճար pilot production scope-ի վրա | Discovery-ն բաց է թողնված. արժեքը վերադառնում է որպես rework |
| Platform license ցանկացած discovery-ից առաջ | Գնում եք նրանց product-ը, ոչ ձեր արդյունքը |
| Exclusions-ի ցուցակ չկա | Scope-ի վեճեր, կանխավճարված |

## Ցածր գնով աշխատանքի թաքնված ծախսերը

Underpriced agent աշխատանքը էժան չի մնում։ Տիպիկ հաջորդող հաշիվներ.

- Rewrite-ներ այն բանից հետո, երբ secrets-ը հայտնվում է client-side կոդում կամ log-երում
- CRM pollution անհսկող automation-ից, որը վատ գրառումներ է գրում մասշտաբով
- Ոչ ոք on-call, երբ agent-ը սխալ է կրակում ուրբաթ գիշերը
- Գիտելիքը հեռանում է contractor-ի հետ, և ամեն փոփոխություն սկսվում է զրոյից
- Երկրորդ վենդոր, որին վճարում են առաջինի համակարգը reverse-engineer անելու համար

Մեկ սխալ ինքնավար գործողության արժեքը - վատ refund batch, սխալ նամակ հաճախորդների ցուցակին, փչացած pipeline - կանոնավոր կերպով գերազանցում է էժան bid-ի և վստահելի bid-ի գնային տարբերությունը։

## Ինչպես համեմատել quote-երը արդար

1. **Normalize արեք scope-ը։** Բոլոր quote-երը դրեք նույն workflow-ի, tools-ի, ծավալի և acceptance test-ի դիմաց։ Եթե վենդորները brief-ը տարբեր կերպ են հասկացել, ուղղեք brief-ը և նորից հարցրեք։
2. **Հարցրեք, թե ինչ է լինում, երբ agent-ը սխալվում է։** Gates, rollback, էսկալացիայի ուղի, on-call։ Վենդորը, որ պատասխան չունի, demo է quote անում։
3. **Հարցրեք, թե ով է վճարում production hardening-ի համար։** Logging, evals, security review. գնի մեջ է, թե change request հետո։
4. **Համեմատեք առաջին տարվա ամբողջ արժեքը։** Build-ի գին գումարած retainer գումարած LLM usage գումարած ձեր թիմի ժամանակը, ոչ միայն pilot-ի տողը։
5. **Կշռեք ownership-ը։** Մի փոքր ավելի թանկ վենդորը, որը փաստաթղթավորում է համակարգը և ուսուցանում ձեր թիմին, վեցերորդ ամսում սովորաբար ավելի էժանն է դուրս գալիս։

## FAQ

### Free pilot-ը լա՞վ ազդանշան է։
Production համակարգերի համար՝ հազվադեպ։ Անվճար աշխատանքը սովորաբար բաց է թողնում discovery-ն, acceptance test-երը և gates-ը՝ այն, ինչ agent-ը դարձնում է անվտանգ։ Դրանց համար կվճարեք հետո՝ որպես rework։

### Պե՞տք է pricing-ը ներառի tools։
Նախընտրեք implementation այն tools-ում, որոնք արդեն ունեք, եթե նոր tool-ը ինքը product-ը չէ։ Quote-ը, որը սկսվում է platform license-ից ցանկացած discovery-ից առաջ, վաճառում է պլատֆորմը, ոչ ձեր արդյունքը։

### Ե՞րբ է retainer-ը արդարացված։
Երբ agent-ները live են և պետք են monitoring, evals և իտերացիա։ Retainer-ն առանց սահմանված scope-ի և արձագանքման ժամանակի standby billing է։

### Ո՞վ պետք է վճարի LLM API հաշիվը։
Սովորաբար դուք՝ ձեր սեփական API key-երով, իսկ վենդորը տալիս է usage-ի գնահատական և cap-եր։ Վենդորի մոտ պահվող key-երը ծախսերը դարձնում են անթափանց, իսկ վենդորի փոխարինումը՝ ավելի դժվար։

### Ինչպե՞ս պլանավորել առաջին տարվա բյուջեն։
Գումարեք չորս տող. audit, pilot, retainer գործարկումից հետո ամիսների համար և LLM usage իրական ծավալով։ Վերևի տիպիկ շուկայական միջակայքերը տալիս են մեկնարկային ծրար. ձեր integrations-ը և ռիսկի պրոֆիլը այն շարժում են վեր կամ վար։
