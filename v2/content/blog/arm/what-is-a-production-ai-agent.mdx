## Ուղիղ պատասխան

Production AI agent-ը համակարգ է, որը կատարում է multi-step աշխատանք tools-ով՝ permissions-ի, human gates-ի, logging-ի և ownership-ի ներքո - ոչ chat window, որը միայն խոսում է։

## Demo agent traits

Միայն happy path։ Real credentials model չկա։ Exception queue չկա։ Stop-switch չկա։

## Production agent traits

Defined inputs/outputs։ Tool contracts։ Approvals։ Eval set։ Monitoring։ On-call story։ Handoff docs։

## Surfaces

Chat, email, tickets, voice, background jobs - surface-ը համակարգը չէ։

## Org implication

Ինչ-որ մեկը տիրապետում է quality-ին vendor-ի հեռանալուց հետո։
