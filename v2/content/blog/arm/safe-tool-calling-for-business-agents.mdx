## Ուղիղ պատասխան

Տվեք agents-ին **փոքր tool allowlists**, least-privilege credentials, explicit schemas, loop limits և human gates irreversible tools-ի վրա։ Tool calling առանց scopes-ի այն է, թե ինչպես demos-ը դառնում են incidents։

## Tool calling vs prompting

Prompting-ը արտադրում է text։ Tool calling-ը թույլ է տալիս model-ին ընտրել structured actions (CRM update, search, send)։ Action layer-ն է, որտեղ ապրում է business risk-ը։

## Allowlists և schemas

Ամեն tool-ի պետք է name, JSON schema, max frequency և owner։ Մերժեք free-form «run any code»-ը production ops-ում։

## Permissions

Առանձնացրեք read tools-ը write tools-ից։ Առանձնացրեք staging credentials։ Ոչ god-mode service accounts agent runtime-ում։

## Loop և spend limits

Max steps, max tokens, max tool calls, wall-clock timeout։ Infinite replanning-ը bug է, ոչ intelligence։

## Assistants platforms

Hosted assistant APIs-ը կարող են օգնել bootstrap-ին։ Դուք դեռ տիրապետում եք scopes-ին, logging-ին և gates-ին business actions-ի համար։
