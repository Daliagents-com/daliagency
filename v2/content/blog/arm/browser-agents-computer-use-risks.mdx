## Ուղիղ պատասխան

Browser և computer-use agents-ը հզոր են և փխրուն։ Օգտագործեք դրանք constrained internal tasks-ի համար recording-ով, least privilege-ով և human gates-ով - ոչ որպես unsupervised employees production admin panels-ի վրա։

## Ինչ են դրանք

Agents, որոնք սեղմում են UIs կամ control են անում desktop, երբ APIs չկան։

## Ինչու են teams-ը ուզում դրանք

Legacy portals, partner sites, no API budget։

## Risks

Credential theft page content-ի միջոցով, prompt injection untrusted HTML-ից, irreversible clicks, non-reproducible failures, audit gaps։

## Ավելի անվտանգ pattern

Dedicated browser profile, vaulted credentials, allowlisted domains, step caps, human confirmation submit/pay/delete-ի վրա, full session logs։

## Նախընտրեք APIs, երբ հնարավոր է

API agents-ը ավելի հեշտ են test, scope և rate-limit անել, քան pixel-level automation-ը։
