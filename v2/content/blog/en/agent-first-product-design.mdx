## Direct answer

In agent-first products, the core job is completed by agents under user goals and constraints. Chat is an interface, not the product. Design goals, tools, memory, evals, and failure UX before polish.

## What good looks like

- Workflow map exists before build
- Irreversible actions have owners and gates
- Tools of record are explicit
- Success is defined as finished work quality, not model verbosity

## What bad looks like

- Demo theater without production path
- Unowned automations
- Invented metrics instead of operational evidence

## FAQ

### Can we skip discovery if we already bought tools?
No. Tools without a workflow map still fail.

### What should we measure first?
Cycle time, rework, and error/incident rate on one path.
