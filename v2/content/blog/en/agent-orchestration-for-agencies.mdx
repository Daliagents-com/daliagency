## Direct answer

For agencies, orchestration means routing work across people, tools, and a small set of agents with clear ownership - not spinning up ten agents because a demo looked cool. Start with one reliable production path per high-volume workflow.

## Agency constraints

Multiple clients, uneven data quality, brand voice on outbound, billable review time.

## Model

1. Intake classify and route
2. Specialist draft
3. Human gate on irreversible client actions
4. Log to system of record
5. Escalate on low confidence

### Multi-agent on day one?
No. One gated path that finishes work beats an unfinished swarm.
