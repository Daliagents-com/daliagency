## Direct answer

A production AI agent is a system that performs multi-step work with tools under permissions, human gates, logging, and ownership - not a chat window that only talks.

## Demo agent traits

Happy path only. No real credentials model. No exception queue. No stop-switch.

## Production agent traits

Defined inputs/outputs. Tool contracts. Approvals. Eval set. Monitoring. On-call story. Handoff docs.

## Surfaces

Chat, email, tickets, voice, background jobs - the surface is not the system.

## Org implication

Someone owns quality after the vendor leaves.

## FAQ

### Are copilots production agents?
They can be, if they take controlled actions with gates.

### Do production agents require multi-agent graphs?
No. One well-designed agent path is enough to start.
