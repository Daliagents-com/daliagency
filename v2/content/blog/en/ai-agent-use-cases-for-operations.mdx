## Direct answer

Operations teams should start AI agents on intake, routing, document-to-system updates, and status sync - always with exception queues and human gates on irreversible writes.

## High-fit use cases

Parse inbound requests into trackers. Validate required fields. Draft status updates. Flag anomalies.

## Low-fit early use cases

Unsupervised vendor payments. Unreviewed legal commitments. Silent deletion of records.

## Design pattern

Standard path automated. Non-standard path to humans. Full log trail.

## Pilot suggestion

One document type or one intake channel first.

### Do we need a data warehouse first?

Inbox, sheets, trackers, CRM, shared drives - whatever you already run.
