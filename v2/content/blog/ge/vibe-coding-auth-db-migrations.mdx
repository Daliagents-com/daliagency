## პირდაპირი პასუხი

Demo logins და wide-open tables არ არის auth. გაუშვით real session handling, least-privilege database rules (RLS) და migrations review-ით - ან დაგეგმეთ data plane-ის rewrite.

## Auth failures vibe apps-ში

Client-only checks, shared passwords, tokens localStorage-ში, missing email verification.

## Sessions

HTTP-only cookies ან proven session libraries; rotate secrets.

## Databases

Enable RLS/policies; no anon write production tables-ზე; separate service roles.

## Migrations

Expand/contract, backups, staging first. AI-generated SQL untrusted-ია სანამ reviewed არ არის.

## როდის rewrite data plane

თუ permissions coherent ვერ ხდება scaffold-თან ბრძოლის გარეშე.
