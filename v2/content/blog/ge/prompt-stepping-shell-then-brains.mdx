## პირდაპირი პასუხი

ჯერ მოითხოვეთ გარსი (ღილაკი, განლაგება, ცარიელი ვიჯეტი), შემდეგ მიამაგრეთ ინტელექტი. ერთი გიგანტური პრომპტი ქმნის გაუმჭვირვალე მარცხებს. ნაბიჯ-ნაბიჯ პრომპტები ქმნის შემოწმებად საკონტროლო წერტილებს.

სწრაფი AI პროტოტიპი (vibe coding) სწრაფია. ის ხდება უკონტროლო, როცა UI, auth, გადახდა და მოდელი ერთ «გააკეთე ყველაფერი» მოთხოვნაში ირევა.

## რას ნიშნავს ეს პრაქტიკაში

- დაიწყეთ რეალური ბიზნეს სამუშაო პროცესიდან, არა მოდელის ბრენდიდან.
- აღწერეთ ქცევა მარტივი ენით, შემდეგ შეამოწმეთ ყველა გზა, რომელიც ეხება ფულს, წვდომას ან გამავალ შეტყობინებებს.
- დატოვეთ ადამიანის გზა არასტანდარტული შემთხვევებისთვის.

## რეკომენდებული ნაბიჯები

1. **Shell** - layout, ნავიგაცია, ცარიელი მდგომარეობები, ღილაკები mock მონაცემებით.
2. **Data shape** - რა ველები შედის/გამოდის; ფორმები რეალური სქემით.
3. **Server boundaries** - API მარშრუტები, auth stub, საიდუმლო გასაღებები სერვერზე.
4. **Intelligence** - მოდელის გამოძახება, retrieval, tool calling - უკვე სტაბილურ გარსზე.
5. **Gates და logs** - ადამიანის კონტროლი, აუდიტი, გაჩერება.
6. **Hardening** - rate limits, webhook, ტესტები კრიტიკულ გზაზე.

## როგორ გამოიყურება კარგი

- ყოველი ნაბიჯის შემდეგ შეგიძლიათ გვერდის/flow-ის ჩვენება და შემოწმება.
- UI ცვლილება არ «არღვევს» მოდელის ქცევას შემთხვევით.
- საიდუმლო გასაღებები არასოდეს კლიენტის JavaScript-ში.
- ლოგები და გაჩერების ღილაკი ჩნდება ინტელექტის შეერთებისთანავე, არა «მოგვიანებით».

## როგორ გამოიყურება ცუდი

- ერთი პრომპტი: «ააშენე SaaS გადახდებით და ჩატბოტით».
- «პრევიუში მუშაობს» რეალური ექსპლუატაციის შემოწმების გარეშე.
- ტოკენები და webhook საჯაროდ.
- გამონაკლისებზე ადამიანთან გადაცემა არ არის.
- თხელი მანქანური გვერდები, როგორც «ლოკალიზაცია».

## FAQ

### სწრაფი AI პროტოტიპი უსარგებლოა?
არა. ეს სწრაფი გზაა სამუშაო ზედაპირისთვის. საშიშია მხოლოდ მაშინ, როცა მას მზა რეალურ ექსპლუატაციად თვლიან.

### ყველაფერს თავიდან წერთ?
არა ყოველთვის. ზოგჯერ ვამყარებთ. ზოგჯერ ვაცალკევებთ და კრიტიკულ გზას თავიდან ვაშენებთ.

### რატომ არ «ერთ პრომპტში ყველაფერი»?
რადგან მარცხი გაუმჭვირვალეა: არ იცით, UI გაფუჭდა, API თუ მოდელის ინსტრუქცია. ნაბიჯები იძლევა დიაგნოზს.
