## პირდაპირი პასუხი

შეაფასეთ AI agent სააგენტო საქართველოში (თბილისი) ისევე, როგორც შეაფასებდით ნებისმიერ სხვაგან: workflow mapping build-ამდე, human approval gates რისკიან მოქმედებებზე, წერილობითი acceptance test-ები, evals და რეალური handoff პაკეტი. ლოკალური შრე ოთხ შემოწმებას ამატებს: time-zone overlap თქვენს გუნდთან, delivery ენა თითოეული artifact-ისთვის (EN/RU/KA), საკონტრაქტო იურისდიქცია და ის, გადარჩება თუ არა ფასის უპირატესობა production მოთხოვნებს. საქართველოს UTC+4 საათი და ხარჯების სტრუქტურა კარგად ერგება EU-სა და Gulf-ის მყიდველებს; production ზღვარი არ იწევს იმის გამო, რომ ოფისი თბილისშია.

## რატომ ჩნდება თბილისი shortlist-ებზე

საქართველოს ტექსექტორი სწრაფად გაიზარდა რამდენიმე სტრუქტურულ უპირატესობაზე: კომპანიის რეგისტრაცია, რომელიც დღეებში იზომება, IT-სთვის ხელსაყრელი საგადასახადო რეჟიმები, ინგლისურად მომუშავე საინჟინრო ბაზარი და 2022 წლიდან რელოცირებული senior ინჟინრების ნაკადი. მყიდველისთვის ეს ითარგმნება რეალურ senior შესაძლებლობებად დასავლეთ ევროპასა და აშშ-ზე დაბალ განაკვეთებში.

ეს არ ითარგმნება ავტომატურ ხარისხად. Demo თეატრი ყველა ფასის დონეზე არსებობს. მისამართი გამოიყენეთ ფასის ასახსნელად; process artifact-ები - შედეგის საპროგნოზოდ.

## Time zone-ები და თანამშრომლობა

საქართველო მთელი წლის განმავლობაში UTC+4-ზე მუშაობს, daylight saving გადაწევების გარეშე. ეს overlap-ის დაგეგმვას უჩვეულოდ პროგნოზირებადს ხდის.

| თქვენი გუნდი | სხვაობა თბილისთან | პრაქტიკული overlap |
| --- | --- | --- |
| დასავლეთ ევროპა (CET) | 2-3 საათით უკან | სამუშაო დღის უმეტესი ნაწილი |
| გაერთიანებული სამეფო | 3-4 საათით უკან | თბილისის შუადღე = ლონდონის დილიდან შუადღემდე |
| Gulf (UAE, KSA) | 0-1 საათი | ფაქტობრივად ერთი დღე, სრული overlap |
| აშშ-ის აღმოსავლეთ სანაპირო | 8-9 საათით უკან | თბილისის გვიანი შუადღე = აშშ-ის დილა |
| აშშ-ის დასავლეთ სანაპირო | 11-12 საათით უკან | Async default-ად, ერთი ვიწრო ფანჯარა |

ნებისმიერ კანდიდატ სააგენტოს სთხოვეთ, წერილობით დაასახელოს საათები, რომლებზეც synchronous სამუშაოსთვის იღებს ვალდებულებას, და ვინ პასუხობს ესკალაციებს მათ მიღმა. "ჩვენ მოქნილები ვართ" პასუხი არ არის; დასახელებული delivery lead განცხადებული საათებით - პასუხია.

## განაკვეთები და რას ყიდულობთ მათში სინამდვილეში

აქ ყველა რიცხვი აღიქვით ტიპურ საბაზრო დიაპაზონად და არა Dali-ს ან რომელიმე კონკრეტული ვენდორის კოტირებად. Blended სააგენტო განაკვეთები AI და automation სამუშაოსთვის თბილისში ჩვეულებრივ $25-60 საათში ზოლში ჯდება, შესადარებელი seniority-ის $100-250-ის წინააღმდეგ აშშ-სა და დასავლეთ ევროპაში. ლოკალური ხარჯების ბაზიდან შეფასებული fixed-scope agent pilot-ები, როგორც წესი, იმავე scope-ის დასავლურ ეკვივალენტებზე საგრძნობლად იაფი გამოდის.

ხაფანგი ის არის, რომ სხვაობა უფასო ფულად წაიკითხოთ. დაბალი განაკვეთი გუნდზე, რომელიც evals-ს, approval gates-სა და observability-ს გამოტოვებს, დაზოგვა არ არის; rework და ინციდენტები სხვაობას მესამე თვისთვის ჭამს. ჯერ production პრაქტიკა შეაფასეთ, შემდეგ კი ფასმა გაარჩიოს ის გუნდები, რომლებმაც შემოწმება გაიარეს.

## იურისდიქცია, კონტრაქტები და გადახდები

- **Entity.** თბილისური გუნდების უმეტესობა ქართული შპს-ით ოპერირებს; ზოგი procurement-ის კომფორტისთვის EU ან US entity-საც ინახავს. ორივე მუშაობს, თუ კონტრაქტი სუფთაა.
- **საგადასახადო რეჟიმები.** საქართველო გვთავაზობს IT-ზე ორიენტირებულ სტატუსებს (Virtual Zone, International Company), რომლებიც ლოკალურ ხარჯების ბაზას მდგრადს ინახავს. პირობები იცვლება; მიმდინარე წესები იურისტთან გადაამოწმეთ.
- **კონტრაქტის საფუძვლები.** ინგლისურენოვანი კონტრაქტები, ცალსახა IP assignment და შეთანხმებული governing law სტანდარტული პრაქტიკაა. სამივე მოითხოვეთ; ყოყმანი IP assignment-ზე დისკვალიფიკაციაა.
- **გადახდები.** სტანდარტული invoicing და SWIFT გადარიცხვები რუტინულად მუშაობს; card rails ბანკის მიხედვით განსხვავდება.
- **მონაცემები.** თუ GDPR-ის ქვეშ ხართ, დაადასტურეთ, სად ინახება logs, traces და prompts, და ხელი მოაწერეთ data processing agreement-ს, სანამ production მონაცემები გაედინება.

## ლოკალური, remote თუ ჰიბრიდი

Local presence ზუსტად ორ რამეს ეხმარება: discovery workshop-ებსა და change management-ს თქვენს თანამშრომლებთან. ყველაფერი დანარჩენი agent delivery-ში remote-friendly-ა. პატერნი, რომელიც მყიდველთა უმეტესობისთვის მუშაობს, ჰიბრიდია: on-site discovery, თუ საქართველოში ხალხი გყავთ, შემდეგ remote build ყოველკვირეული demo-ებით, approval gates-ითა და წერილობითი acceptance test-ებით. ნუ გადაიხდით პრემიუმს ლოკალურ ოფისში, თუ ის, რაც გჭირდებათ, gate map-ია.

## Delivery ენა

სამი ენობრივი შრე ცალ-ცალკე დაადასტურეთ, რადგან პრაქტიკაში ისინი ერთმანეთს შორდება:

1. User-facing agent surface-ები: ქართული მხოლოდ მაშინ, თუ თქვენს users-ს სჭირდებათ.
2. Ops დოკუმენტაცია, runbook-ები და eval აღწერები: ჩვეულებრივ ინგლისური.
3. ყოველდღიური თანამშრომლობა: თბილისის ბაზარზე ინგლისურიც და რუსულიც გავრცელებულია.

გუნდს შეუძლია demo თავისუფალ ინგლისურზე ჩაატაროს და მაინც ჩაგაბაროთ runbook-ები, რომლებსაც თქვენი ops გუნდი ვერ წაიკითხავს. თითოეული artifact-ის ენა კონტრაქტში ჩაწერეთ.

## რა იყიდოთ ლოკალურად

Production pilot, თქვენს tools-ზე მიბმული, და არა generic chatbot პაკეტი:

- ერთი workflow, წერილობით დარუკული, სანამ რაიმე build დაიწყება
- Acceptance test-ები, წინასწარ შეთანხმებული და დასრულებული სამუშაოს ხარისხზე მიბმული
- Approval gates შეუქცევად მოქმედებებზე პირველივე დღიდან, რომლებიც ნდობის ზრდასთან ერთად იხსნება
- Eval set regression შემოწმებებით ყოველი release-ის წინ
- Logs და traces, რომლებსაც ვენდორის დასწრების გარეშე წაიკითხავთ
- Handoff პაკეტი: docs, runbook, credentials გეგმა და განსაზღვრული exit პირობები

## FAQ

### Local რეგისტრაცია აუცილებელია დასაქირავებლად?
არა. ეს procurement-ის პრეფერენციაა და არა ტექნიკური მოთხოვნა. ბევრი მყიდველი ქართულ შპს-სთან პირდაპირ აფორმებს კონტრაქტს შეთანხმებული governing law-ის ქვეშ; სხვები ვენდორის EU ან US entity-ის გავლით მიდიან. ტექნიკური ხარისხი დოკუმენტბრუნვის გზისგან დამოუკიდებელია, ამიტომ entity-ის საკითხი procurement-თან მოაგვარეთ და diligence-ის დრო process artifact-ებზე დახარჯეთ.

### უნდა მოვითხოვოთ ქართულენოვანი UI agent-ები?
მხოლოდ მაშინ, თუ თქვენს users-ს ქართული სჭირდებათ. Cross-border engagement-ების უმეტესობა ინგლისურ ან რუსულ user surface-ებს უშვებს. ორივე შემთხვევაში მნიშვნელოვანი ops შრეა: runbook-ები, ესკალაციის docs და eval აღწერები იმ ენაზე უნდა იყოს, რომელსაც თქვენი გუნდი რეალურად კითხულობს, და ეს კონტრაქტში ეკუთვნის და არა ვარაუდებში.

### რას ახდევინებენ ჩვეულებრივ თბილისური სააგენტოები agent სამუშაოსთვის?
მხოლოდ ტიპური საბაზრო დიაპაზონების სახით: blended განაკვეთები ჩვეულებრივ $25-60 საათში ზოლში ზის, fixed-scope pilot-ები კი შესაბამისად ფასდება. შეადარეთ პირველი წლის სრული ღირებულება - build, retainer, LLM usage, თქვენი გუნდის დრო - და არა საათობრივი ეტიკეტი, ხოლო ვენდორი, რომელიც თქვენს მოცულობაზე LLM ხარჯებს ვერ აფასებს, დაუმტკიცებლად ჩათვალეთ.

### რამდენი time-zone overlap უნდა მოვითხოვოთ?
