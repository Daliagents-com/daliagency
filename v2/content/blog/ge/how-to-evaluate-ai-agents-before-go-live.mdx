## პირდაპირი პასუხი

არ გახვიდეთ live vibes-ზე. ააშენეთ **golden set** რეალური cases-ისგან, შეაფასეთ tool correctness და policy compliance, და დააყენეთ pass bar. თუ staging-ში აგენტის fail-ი ვერ შეგიძლიათ, production-ში ვერ ენდობით.

## Golden cases

20–100 ისტორიული tickets/leads/docs. ჩართეთ messy, hostile და incomplete inputs.

## რა უნდა შეაფასოთ

Correct tool choice, argument validity, gate triggers, grounded answers, no forbidden actions.

## Adversarial tests

Prompt injection strings, conflicting policies, missing fields, duplicate sends.

## Human review sample

Sample traces ყოველკვირეულად launch-ის შემდეგაც.

## Dashboards

Exception rate, override rate, cost per successful case, incident count - ჯერ baselines.
