## პირდაპირი პასუხი

არასოდეს გააზიაროთ raw client knowledge indexes, credentials ან conversation memory tenants-ზე. Isolate-ეთ client-ით storage-ზე, retrieval-სა და tool-credential layers-ზე - “one big prompt with all clients” breach-ია, რომელიც ელოდება.

## რატომ fail-დებიან agencies ამაზე

Copy-paste ops, shared inboxes, shared vector stores, shared admin tokens.

## Isolation layers

Auth tenant id, separate secrets, separate indexes, separate logging streams სადაც საჭიროა.

## Prompts

Shared skill templates OK; client facts და credentials არასოდეს baked-დება shared system prompts-ში.

## Multi-store routing

Explicit brand/store id ყოველ tool call-ზე - არა “guess the store from vibe”.
