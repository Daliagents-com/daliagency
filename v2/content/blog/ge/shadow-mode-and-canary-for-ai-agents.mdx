## პირდაპირი პასუხი

გაუშვით აგენტები როგორც risky software: **shadow mode** (predict without acting), შემდეგ **canary** (პატარა % ან ერთი segment), versioned prompts-ით და instant rollback-ით. Big-bang “ყველა ticket ხვალ” არის ის, როგორ კვდება trust.

## Shadow mode

აგენტი სთავაზობს მოქმედებებს; ადამიანები ან current process მაინც მოქმედებენ. შეადარეთ offline.

## Canary

ერთი queue, ერთი locale, ერთი VIP-excluded segment. უყურეთ exception და override rates-ს.

## Prompt/version control

მოექეცით prompts-სა და tool schemas-ს როგორც code-ს: review, tag, release notes.

## Feature flags

Flip behavior whole stack-ის redeploy-ის გარეშე, როცა შესაძლებელია.

## Rollback

Known-good prompt + tool config ერთი click-ით. ივარჯიშეთ.
