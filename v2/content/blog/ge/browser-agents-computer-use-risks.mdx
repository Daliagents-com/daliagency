## პირდაპირი პასუხი

Browser და computer-use აგენტები ძლიერი და მყიფეა. გამოიყენეთ constrained internal tasks-ისთვის recording-ით, least privilege-ით და human gates-ით - არა როგორც unsupervised employees production admin panels-ზე.

## რა არის ისინი

აგენტები, რომლებიც აჭერენ UIs-ს ან აკონტროლებენ desktop-ს, როცა APIs აკლია.

## რატომ სურთ გუნდებს

Legacy portals, partner sites, no API budget.

## რისკები

Credential theft page content-ის მეშვეობით, prompt injection untrusted HTML-იდან, irreversible clicks, non-reproducible failures, audit gaps.

## უფრო უსაფრთხო pattern

Dedicated browser profile, vaulted credentials, allowlisted domains, step caps, human confirmation submit/pay/delete-ზე, full session logs.

## უპირატესობა APIs-ს, როცა შესაძლებელია

API agents უფრო ადვილია test-ისთვის, scope-ისა და rate-limit-ისთვის, ვიდრე pixel-level automation.
